# Novel

Novel 是一个纯本地的 AI 长篇小说创作系统。

Codex 是创作、推理、检索决策和审核的大脑；Novel Plugin 与 CLI 为 Codex 提供多小说
管理、创作环境、导航记忆、准确原文、草稿版本、审核记录、批准和发布工具。

完整业务闭环是：

```text
选择或创建小说
→ 作者与 AI 讨论小说方向
→ 保存并批准小说前置内容
→ 建立 Writing Session
→ AI 按需查询意图、摘要、Canon 和正式原文
→ 保存并修订草稿
→ AI Reviewer 审核并继续查询
→ 生成摘要与可选关键 Canon
→ 作者查看 Diff 并批准准确 Digest
→ 应用事务性发布
→ 新正文和记忆进入下一次创作
```

系统保证 ID、版本、引用、存储、审批和恢复等机械准确性，不用固定算法代替 AI 判断
人物、剧情、声音、因果、节奏、情绪或历史信息是否充分。

架构与业务规则以 [设计文档索引](./docs/README.md) 为唯一依据。
